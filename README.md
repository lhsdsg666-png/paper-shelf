# 纸间

纸间是一款在 GitHub Pages 上运行的私人小说阅读器。打开网页，点击 **导入文件夹**，选择装有小说和插图的目录。也可以拖入文件夹，或通过 **选择文件** 导入文件和 ZIP。

## 安装到手机桌面

- 安卓 Chrome：打开纸间，点右上角菜单，选择 **添加到主屏幕** 或 **安装应用**。
- iPhone Safari：点 **分享 → 添加到主屏幕**。如果有 **作为网页 App 打开**，请保持开启。Safari 和 iPhone 桌面版使用各自的本地书架。安装后可从图标打开，再导入文件。
- 在使用纸间的浏览器或桌面版里联网打开一次，待网页资源缓存完成后，即可离线打开并阅读已导入的小说。请保留小说和插图的原文件。

## 文件格式

- 小说支持 TXT、Markdown 和无 DRM 的 EPUB。TXT 识别 UTF-8、带 BOM 的 UTF-16 和常见 GBK / GB18030 编码。
- 多个 TXT / Markdown 文件可分别导入，也可按文件名的自然顺序合并成一本，例如第 2 章排在第 10 章前面。
- 插图支持 JPG、PNG、GIF、WebP、AVIF 和 BMP。目录里有与书名同名的图片或名为 cover / 封面 的图片时，优先显示为封面。书内的 **插图** 按钮可打开相册。
- Markdown 可用相对路径引用插图，例如 ![月色](images/moon.png) 的 Markdown 图片语法。TXT 可用单独一行「插图：images/moon.png」引用。EPUB 按书中的阅读顺序显示内嵌插图，外部网页资源不会加载。
- 手机文件选择器如果无法选整个目录，可以先压缩为 ZIP，再选择压缩包。每个普通文件最多 32 MB，单批目录文件或每个 ZIP 解压后的受支持文件最多 300 MB。
- 重复导入同一本书会保留已有书籍与进度。要更新同一本书的插图，可保留原文件，移出原有书籍后重新导入。

## 本地数据

正文、图片和进度存储在当前网站的 IndexedDB 中，阅读设置保存在当前浏览器的本地存储中。网站没有账号、后端上传接口、遥测或外部 CDN 依赖。网页的内容安全策略禁止脚本发出网络连接，也禁止从外部网址加载插图。离线缓存只包含固定的网站资源。导入的文件会经过本地解析，图像通过临时 Blob URL 显示。

同一网址在不同浏览器、浏览器用户配置和设备上各有自己的书架。共享同一个浏览器配置的人可以读到里面的书。清除网址的站点数据、使用无痕窗口或浏览器回收存储空间可能丢失书库。请保留原始小说和插图。

## 开发和部署

在 Node.js 22 或以上版本运行 npm ci 和 npm run build。运行 npm run preview 在本机通过 Python 静态服务器预览。

GitHub Pages 的发布源选择 **Deploy from a branch → main → /docs**。更新前端代码或网页资源后运行 npm run build，把产物随源码一同提交。构建时会根据发布文件内容生成离线缓存版本。发布目录 docs/ 仅包含网页资源。
